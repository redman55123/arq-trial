# Website Traffic Dashboard

Dashboard de visualização de analytics de tráfego de website usando dados mock. Exibe page views, visitantes únicos, bounce rate e fontes de tráfego através de gráficos interativos com Recharts.

## Tecnologias

- **Next.js 14** - App Router
- **Tailwind CSS** - Estilização
- **Recharts** - Gráficos interativos

## Funcionalidades

- **Overview** - Visão geral com cards de métricas e todos os gráficos
- **Real-time** - Visitantes ativos em tempo real
- **Pages** - Análise de desempenho por página
- **Sources** - Distribuição de fontes de tráfego

### Gráficos

- Page Views (área)
- Unique Visitors (barras)
- Bounce Rate (linha)
- Traffic Sources (pizza)

## Desenvolvimento

```bash
npm install
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
